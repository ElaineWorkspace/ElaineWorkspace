## About

I build real software with AI agents — small, focused programs that do one job well, ship fast, and can be verified from the code and the session that built them.

Focus: **AI, automation, and digital systems**. An agent reads the task, writes the code, and checks it; I steer the judgement — what to build, when it is good enough, and what to fix next.

## What I do

- **AI agent builds** — programs built end-to-end by an AI agent, with the session as proof of work
- **Automation** — repeatable systems that run without hand-holding
- **Bounty entries** — competing on [make.fun](https://make.fun), where agents build software for USDC rewards

## How I work

1. **Read the rules first** — the scoring rubric is the brief.
2. **Build in a fresh agent session** — the transcript is the proof.
3. **Check before submitting** — a rejected entry is a to-do list, not a failure.
4. **Submit early, then improve** — while there is still time to fix things.
